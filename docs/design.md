# Homepage design specification

## Direction

Swiss International Typographic Style: an asymmetric twelve-column grid, large tightly tracked grotesk typography, open space, fine rules, and a vermilion mathematical wave study. Three coordinated built-in Image Gen concepts define hero, about/research, and projects/contact. They are design references, not rasterized page content.

## System

- Light: paper `#f5f5f2`, ink `#171715`, accent `#ed3d23`, rule `#bcbcb6`.
- Dark (requested by user): paper `#171715`, ink `#f5f5f2`, accent `#ed3d23`, rule `#4b4b46`.
- Typography: Helvetica Neue, Helvetica, Arial; bold display, regular body; monospace labels for the wave controls. Scale: hero 72–172px, section 42–82px, project 28–54px, body 18–22px, utility 12–14px.
- Containers: 48px desktop gutters, 20px mobile gutters, max content width 1600px; no card grid, shadows, radiused containers, or photographic overlays.
- Icon family: thin square-ended SVG arrows and plus/minus signs. Theme and language are native buttons.
- Components: compact sticky header, two-line hero, interactive canvas, three-column facts, asymmetric about rail, inverse research accordion, ruled project disclosures, solid red contact footer.

## Motion and functional deviations

Native text/controls throughout. The hero field is a real procedural mathematical canvas so pointer/frequency input can reshape it, an intentional functional extension of the generated reference. It is a visual study, not experimental data. Entrance text masks, staggered scroll reveals, animated disclosure content, line/arrow hover transitions, active navigation, and reading progress provide motion without scroll interception. Controls include a keyboard-accessible frequency slider and pause button. Respect reduced motion in CSS and JS, suspend offscreen canvas and hidden-document rendering, cap device pixel ratio.

English and Chinese share the same composition with language-specific type scaling. Native details preserve content access without JavaScript; mobile navigation works as a disclosure. Theme and language persist locally with graceful storage failure handling.


## User-directed extensions during implementation

The owner requested stronger physical interaction after reviewing the wave field. The hero therefore becomes an actual softened inverse-square gravity experiment with draggable particle launches, adjustable attraction, keyboard launch, pause, and reset. The original reference still governs typography, palette, asymmetric layout and canvas placement; the revised physical behavior supersedes its wave artwork.

The owner authorized retrieving project material from their other chats. The final selected work includes Cell stress, EnergyBench, Elastocapillarity, Research Atlas, and Wenhao’s Arcade. Real figures live in expandable rows and open into a native image dialog. The cell study replaces its original video with a live canvas rendering of original saved numerical fields, including selectable area/myosin, timeline, playback and approximate local probes. This is an intentional user-requested functional extension. Affiliation names link to the two exact group URLs supplied by the owner.

The metadata and homepage copy reflect the supplied identity and expected graduation. Small red text is darkened in light mode and lightened in dark mode for readable contrast. Project artwork is not tinted or recolored; only the interactive numerical field uses the site color scale with an explicit legend.
